# Officer workflow

1. Sign in and open **Dashboard** for operational metrics.
2. Select **New inspection**, add a product context, and upload a clear package image.
3. Start analysis. The application shows only server-confirmed workflow states.
4. Open the assessment. Review the original image, clickable OCR regions, extracted declarations, and rule table.
5. Treat **Pass** as an automated declaration-presence result only. Review font size, placement, legibility and other unimplemented checks manually.
6. Record the reviewer assessment and notes without altering the automated result.
7. Generate the PDF/DOCX compliance report when appropriate.
8. Use Inspections, Products, Violations, Reports, or global search to retrieve the evidence later.
